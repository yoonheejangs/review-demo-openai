석사학위논문 심사용 실험 플랫폼 데모

본 데모는 실제 본실험의 구조인 사전 설문 → 조건별 실험 → 사후 설문 흐름을 심사위원께서 확인하실 수 있도록 재구성한 버전입니다. 입력 내용은 연구 원자료로 저장되지 않습니다.

1

사전 설문

기본 정보, AI 이미지 생성 경험, 디지털 활용 경험, PECS 및 자기효능감 사전 문항의 구성을 확인합니다.
2

조건별 실험

Control, Context, Advanced 조건에서 학습자가 어떤 UI와 처치를 경험했는지 체험합니다.
3

사후 설문

사후 PECS, 자기효능감, 만족도, 인지부하, 조건별 경험 문항 구성을 확인합니다.

조건별 실험 화면 바로가기

Control

기본 가이드 + 자유 작성

영상 시청 후 목표 이미지를 보고 자유롭게 프롬프트를 작성합니다.

 Context

블록 조립 + Shadowing

블록 선택 → 문장화 → 직접 타이핑 과정을 통해 프롬프트 구조를 익힙니다.

 Advanced

단계별 도전 + 점수 피드백

초급·중급·고급 도전과 피드백을 통해 이미지를 정교화합니다.
