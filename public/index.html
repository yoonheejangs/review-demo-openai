석사학위논문 심사위원용 데모 안내

실제 실험 참여자가 경험한 온라인 실험 환경을 심사위원께 미리 확인받기 위해 구성한 데모 버전입니다. OpenAI 기반 이미지 생성 및 AI 가이드는 활성화되어 있으며, 입력 내용은 연구 원자료나 Google Sheet로 저장되지 않습니다.

분리된 심사용 환경

원본 실험 링크와 별도로 복사·수정된 심사용 환경으로 구성되어 있어 원자료를 건드리지 않습니다.

OpenAI 체험 가능

Group 1~3에서 프롬프트 가이드와 이미지 생성 기능을 실제로 눌러보실 수 있습니다.

비밀번호 보호

심사위원 전용 비밀번호 페이지를 통해 접근을 제한할 수 있도록 구성되어 있습니다.

핵심 안내
• 본 데모는 OpenAI API를 서버 측에서 호출합니다.
• 브라우저에 API 키가 노출되지 않습니다.
• 심사위원이 작성한 응답과 프롬프트는 저장되지 않습니다.

전체 실험 흐름

사전 안내 → 그룹별 과제 → 이미지 생성 → 사후 설문 구조를 한눈에 확인할 수 있습니다.

Group 1 (Control)

기본 가이드 영상을 본 뒤 자유롭게 프롬프트를 작성하는 조건입니다.

Group 2 (Context)

블록 조합과 AI 문장 제안을 통해 프롬프트 구조를 익히는 조건입니다.

Group 3 (Advanced)

전문가 예시·5대 요소·레벨 기반 도전과 피드백을 제공하는 조건입니다.

심사위원께서 확인하실 수 있는 내용

1. 실험 UI 흐름

참여자가 어떤 절차를 거쳤는지 화면 중심으로 확인합니다.

2. 조건별 처치 차이

Control / Context / Advanced 조건의 설계 차이를 비교합니다.

3. OpenAI 기반 체험

일부 데모에서 AI 가이드와 이미지 생성을 직접 눌러볼 수 있습니다.

4. 사후 설문 구조 확인

측정 문항 구성을 입력 부담 없이 살펴볼 수 있습니다.
